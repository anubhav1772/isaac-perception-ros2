# isaac-perception-ros2

# AlienGo + Isaac Gym + ROS2 Perception Pipeline

This project integrates:

- AlienGo (Isaac Gym) for simulation  
- ROS2 bridge (ZMQ) for sensor streaming  
- RTAB-Map for SLAM  
- YOLOv8 for object detection  
- RViz2 for visualization  

## Pipeline Overview

Isaac Gym → ZMQ Bridge → ROS2 Topics → RTAB-Map (SLAM) → YOLOv8 (Object Detection) → RViz Visualization 

## Setup

Clone the Isaac Gym assets:

```bash
git clone https://github.com/anubhav1772/isaacgym_assets.git
```

Build and source your ROS2 workspace:

```
colcon build --packages-select isaac_bridge object_detection --symlink-install
source install/setup.bash
```

### Terminal 1 — Run Simulation
```
python scripts/explore.py
```

### Terminal 2 — Isaac to ROS Bridge
```
ros2 run isaac_bridge zmq_bridge
```

Publishes:

- /camera/rgb/image_raw  
- /camera/depth/image_raw  
- /camera/rgb/camera_info  
- /ground_truth/odom

### Terminal 3 — SLAM (RTAB-Map)

Start RTAB-Map with RGB-D input and ground-truth odometry:

```bash
ros2 run rtabmap_slam rtabmap \
  --delete_db_on_start \
  --RGBD/CreateOccupancyGrid true \
  --Grid/Sensor 1 \
  --Grid/3D false \
  --Grid/RangeMin 0.1 \
  --Grid/RangeMax 5.0 \
  --Grid/CellSize 0.05 \
  --Reg/Force3DoF true \
  --ros-args \
  -r rgb/image:=/camera/rgb/image_raw \
  -r depth/image:=/camera/depth/image_raw \
  -r rgb/camera_info:=/camera/rgb/camera_info \
  -r odom:=/ground_truth/odom \
  -p frame_id:=base_link \
  -p approx_sync:=true
```
  
Alternatively, as a single command:
```
ros2 run rtabmap_slam rtabmap --delete_db_on_start --RGBD/CreateOccupancyGrid true --Grid/Sensor 1 --Grid/3D false --Grid/RangeMin 0.1 --Grid/RangeMax 5.0 --Grid/CellSize 0.05 --Reg/Force3DoF true --ros-args -r rgb/image:=/camera/rgb/image_raw -r depth/image:=/camera/depth/image_raw -r rgb/camera_info:=/camera/rgb/camera_info -r odom:=/ground_truth/odom -p frame_id:=base_link -p approx_sync:=true
```

This configuration provides:
- RGB-D SLAM using the simulated camera
- RTAB-Map pose graph
- 2D occupancy grid for Nav2
- 5 cm occupancy-grid resolution
- Depth observations between 0.1 m and 5.0 m
- Planar (3DoF) registration suitable for ground navigation
- `map → odom` transform from RTAB-Map
- Fresh RTAB-Map database on every run

--`delete_db_on_start` is useful during development and repeatable mapping tests. Remove it when you want RTAB-Map to reuse an existing database.

### Terminal 4 — Object Detection
```
ros2 run object_detection object_detection_node
```
Publishes:

- /detected_objects (PointCloud2)

### Terminal 5 — Visualization
```
rviz2
```

## Recommended configuration:

- Fixed Frame: `odom` or `map`

Add the following displays:

1. **Image**
   - Topic: `/camera/rgb/image_raw`
   - Type: `Image`
   - Purpose: View RGB camera feed

2. **PointCloud2 (SLAM Map)**
   - Topic: `/cloud_map`
   - Type: `PointCloud2`
   - Purpose: Visualize 3D map generated by RTAB-Map

3. **PointCloud2 (Detected Objects)**
   - Topic: `/detected_objects`
   - Type: `PointCloud2`
   - Purpose: Visualize detected objects projected into 3D

4. **Map**
   - Topic: `/map`
   - Type: `Map`
   - Purpose: View 2D occupancy grid from RTAB-Map

Optional additions:

- **TF**
  - Type: `TF`
  - Helps visualize coordinate frames

- ultralytics (YOLOv8)
